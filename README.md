# Gradland

Materials for [`Gradland: On Phenomenal Experience, Differentiated Across Many Dimensions`](https://arxiv.org/abs/2609.09306) and [`Power over Metabolic Fire: Minimal Models of Affect, Purpose and Norms`](https://github.com/dbalduzzi/gradland/blob/main/papers/metabolic_fire.pdf).

- [`code/`](code/) — the open-source implementation: input/parameter Jacobians, transparency, cohesion, cohesive rank, and a worked-example notebook. See [`code/README.md`](code/README.md).
- [`What is it like to be a neural net?`](https://www.lesswrong.com/posts/zsxcCmwGbWLFcNN7i/what-is-it-like-to-be-a-neural-net) and [`What is it like to be alive?`](https://www.lesswrong.com/posts/7xDhJr2whSoRvJkpj/what-is-it-like-to-be-alive) — LessWrong posts
- [`slides`](https://dbalduzzi.github.io/gradland/slides/gradland_talk.html)
